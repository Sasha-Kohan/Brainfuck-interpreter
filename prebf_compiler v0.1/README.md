# preBF — компилятор в Brainfuck

Компилятор читает `program.prebf`, разбирает команды, проверяет объявления и генерирует обычный Brainfuck в `program.bf`. В проекте нет сторонних зависимостей.

## Быстрый запуск

Требуется Python 3.10 или новее.

```bash
python main.py
```

По умолчанию компилируются `program.prebf` → `program.bf` с разрядностью 8 бит. Пути и разрядность можно задать явно:

```bash
python main.py --input program.prebf --output program.bf --bits 8
```

Поддерживаются `--bits 8` и `--bits 16`. Запускать скомпилированную программу нужно в Brainfuck-интерпретаторе с такой же шириной ячейки: ячейки содержат двоичный код числа в дополнительном коде, арифметика заворачивается по модулю `2**bits`. Для стандартных 8-битных ячеек используйте `--bits 8`.

## Синтаксис `program.prebf`

```text
// Комментарий: только если // стоят в первом столбце
new a
a := 67
a := b + c
a := b - c
input a
output(a)
if a == b
	output(a)
else
	output(b)
```

Блоки `if` и `else` выделяются табуляцией, один таб — один уровень вложенности. Пустые блоки допустимы. `else` должен находиться на том же уровне отступа, что и соответствующий `if`. Переменные объявляются через `new` до первого использования; повторные объявления и обращения к необъявленным переменным приводят к ошибке.

`input a` читает десятичное целое со стандартного ввода, пропускает начальные пробелы/табуляции/переводы строк и поддерживает знак `+` или `-`. Число должно быть корректным; после него рекомендуется ставить пробел или перевод строки. `output(a)` печатает десятичное знаковое значение и перевод строки.

## Архитектура

- `prebf/ast.py` — узлы AST.
- `prebf/parser.py` — синтаксический анализ и проверка отступов.
- `prebf/semantics.py` — объявления и ссылки на переменные.
- `prebf/bf.py` — генератор BF и реализации арифметики, ввода/вывода.
- `prebf/compiler.py` — публичный API `compile_source()`.
- `prebf/cli.py` — командная строка.

Чтобы добавить цикл, новый оператор или тип данных, добавьте узел AST, разберите его в парсере, проверьте в семантическом проходе и реализуйте кодогенерацию в backend. Такой разнос позволяет позже добавить другой backend без переписывания парсера.

## Ограничения текущей версии

- Поддерживаются 8- и 16-битные ячейки. Для совместимости с большинством BF-интерпретаторов используйте 8 бит.
- В стандартном Brainfuck нет операций сравнения и десятичного ввода/вывода, поэтому backend генерирует вспомогательные циклы. Числовые операции и вывод крупных значений могут выполняться медленно, особенно с 16-битными ячейками.
- Сейчас поддерживается только условие равенства `if a == b`; циклы и другие сравнения оставлены для следующих расширений.
