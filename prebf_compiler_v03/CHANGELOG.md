# Changelog

## v0.3.0

- Added arithmetic expressions with unary signs, parentheses, `+`, `-`, and `*`.
- Added declaration initialization: `new name = expression`.
- Changed preferred assignment syntax to `name = expression` (kept `:=` as a compatibility alias).
- Added signed `==`, `!=`, `<`, `<=`, `>`, and `>=` conditions.
- Added `if` / `else if` / `else` branches with colon headers and tab-indented bodies.
- Added `while` and C++-style `for (init; condition; update):` loops.
- Added `++`, `--`, `+=`, and `-=` update forms.
- Updated examples, documentation, and regression tests.
