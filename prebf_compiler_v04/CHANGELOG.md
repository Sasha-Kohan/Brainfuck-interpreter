# Changelog

## 0.4.0
- Added `int`, `char`, and `bool` declarations and automatic assignment conversions.
- Added two-field `pair<T, U>` values with `.first` and `.second` members.
- Added fixed and runtime-sized arrays, array indexing, and read-only `.size()`.
- Added runtime dispatch for variable array indices in ordinary statements and `if` conditions.
- Added comma-separated declarations with independent initializers.
- Added raw character input/output and `char` truncation to eight bits.
- Added a `--max-array-size` setting for dynamically-sized arrays.

## 0.3.0
- Added arithmetic expressions, unary signs, comparisons, `while`, and `for` loops.
- Changed assignment syntax to `=` while retaining the legacy spelling.
